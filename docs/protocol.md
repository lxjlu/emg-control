# 手势控制协议 v2（App ↔ SDK）

这是 App 与 SDK 之间**唯一的跨语言契约**。实现语言不限（当前 App 为 Java，SDK 为 Python），
只要遵守本文即可互通。

> 设计原则：协议只描述「要做什么动作」，不描述「哪个设备怎么实现」。
> 设备差异全部留在 SDK 的适配器里。

---

## 1. 传输与编码

| 项 | 约定 |
|---|---|
| 传输 | UDP 单播（IPv4） |
| 默认端口 | `8888` |
| 编码 | UTF-8 JSON，一个数据报 = 一条消息 |
| 分帧 | 无长度前缀、无分包；单包建议 < 1500 字节 |
| 字节序 | 与 JSON 无关；仅旧版侦察球二进制协议涉及小端/大端（见 §7） |

一个 SDK 进程只绑定一个端口、只服务一个适配器。需要同时控制多种设备时，
启动多个进程并使用不同端口（App 侧按设备类型填端口）。

---

## 2. 版本策略

- 顶层字段 `v` 表示协议版本，缺省视为 `2`。
- 接收方遇到不认识的版本必须**丢弃并记录错误**，不得按旧语义猜测。
- 新增**可选**字段属于兼容变更，不升版本；删除字段、改变字段含义必须升版本。
- 当前版本：`2`。

## 3. 消息定义

### 3.1 连续运动 `move`

```json
{"v":2,"seq":1024,"act":"move","arg":{"vx":0.60,"wz":0.00}}
```

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `v` | int | 否 | 协议版本，默认 2 |
| `seq` | int | 否 | 序号，用于去重 |
| `act` | string | 是 | 固定为 `move` |
| `arg.vx` | float | 否 | 前后速度，`-1..1`，正为前进，缺省 0 |
| `arg.wz` | float | 否 | 转向速度，`-1..1`，正为左转，缺省 0 |
| `token` | string | 否 | 共享令牌，服务端启用校验时必填 |

`vx / wz` 是**归一化值**，由适配器按自己的能力换算成物理量：

| 适配器 | `vx = 1` | `wz = 1` |
|---|---|---|
| go2 | 0.8 m/s | +2.0 rad/s |
| go2w | 0.5 m/s | +1.0 rad/s |
| ball | drive = 1000 | steer = -1000 |
| car | `forward` | `left` |

### 3.2 停止 `stop`

```json
{"v":2,"seq":1025,"act":"stop"}
```

接收方应立即停止，并保持停止状态直到收到新的 `move`。可重复发送，处理需幂等。

### 3.3 离散动作

```json
{"v":2,"seq":1026,"act":"next"}
```

| `act` | 含义 |
|---|---|
| `next` / `prev` | 下一页 / 上一页（PPT） |
| `start` / `exit` | 开始放映 / 退出放映 |
| `open` / `close` | 夹爪张开 / 并拢 |

离散动作**只执行一次**，不参与心跳，也不需要重复发送。

### 3.4 能力查询 `hello`

```json
{"v":2,"act":"hello"}
```

### 3.5 应答

普通应答：

```json
{"ok":true,"act":"move"}
```

错误应答：

```json
{"ok":false,"error":"协议版本不支持: 3（本端为 2）"}
```

`hello` 的应答是能力描述（字段随适配器扩展）：

```json
{
  "ok": true,
  "v": 2,
  "port": 8888,
  "token_required": false,
  "type": "go2",
  "name": "Go2 机械狗",
  "actions": ["move", "stop"],
  "continuous": true,
  "publish_hz": 10.0,
  "deadman_ms": 600,
  "max_speed": {"vx": 0.8, "wz": 2.0}
}
```

侦察球适配器还会返回 `max_speed.drive / max_speed.steer` 与 `route`；
机械车返回 `target`；PPT 返回 `platform` 且 `continuous=false`。

App 应据此决定手势映射（只映射 `actions` 里存在的动作）。

### 3.6 肌电波形流 `stream`

App 采集时可选把原始样本推给 SDK，用于在浏览器查看 8 通道波形。
它与命令共用同一个 UDP 端口，但**不参与心跳、不触发 deadman、不需要应答**。

```json
{
  "v": 2,
  "type": "stream",
  "seq": 12,
  "rate": 500,
  "ch": 8,
  "n": 25,
  "data": "AADeAPz//v8BAAIA..."
}
```

| 字段 | 必填 | 说明 |
|---|---|---|
| `type` | 是 | 固定 `"stream"`，服务端据此与命令分流 |
| `ch` | 否 | 通道数，1~8，默认 8 |
| `rate` | 否 | 采样率 Hz，1~5000，默认 500 |
| `n` | 是 | 本包样本数，1~200 |
| `data` | 是 | `n × ch` 个**小端 int16**，按样本交错，再 base64 |
| `seq` | 否 | 包序号，仅用于排查丢包 |

编码示例（8 通道，2 个样本）：

```
样本1: 100 -200 300 -400 500 -600 700 -800
样本2: 101 -201 301 -401 501 -601 701 -801
      ↓ 小端 int16 交错
64 00 38 FF 2C 01 70 FE F4 01 A8 FD BC 02 E0 FC ...
      ↓ base64
ZA...（整段）
```

约定：

* 单包建议 20~50ms 的数据（500Hz 下 10~25 个样本），避免超过 MTU；
* App 每凑满 25 个样本发一包即可，无需等待；
* 接收端按全局样本序号做增量，序号由接收端自己维护，`seq` 不参与去重；
* 没有推送时监控页面显示「等待数据」，不影响命令通道。

验证：

```bash
python -m emg_sdk monitor --port 8888 --http-port 8080
# 浏览器打开 http://<SDK 主机 IP>:8080
```

## 4. 时序语义

| 规则 | 说明 |
|---|---|
| 心跳 | `move` 必须按适配器的 `publish_hz`（10~20Hz）持续发送 |
| 看门狗 | 超过 `deadman_ms` 未收到新的 `move`，接收方**自动 `stop`** |
| `stop` | 发送一次即可；接收方不重复执行 |
| `seq` | 可选。接收方丢弃与上一条 `seq` 相同的报文 |
| 断链 | 对 UDP 无感知，依赖看门狗；TCP/WebSocket 实现应在连接断开时 `stop` |

App 侧建议：手势识别结果变化时立即发一帧；此后按 50ms 周期续发同一命令，
直到识别为「休息」或低置信度时发 `stop`。

---

## 5. 令牌（可选）

服务端以 `--token` 启动后，只接受 `token` 字段完全一致的报文，其余静默丢弃并记日志。
`hello` 应答中的 `token_required` 告知客户端是否需要携带。

---

## 6. 错误处理

| 情况 | 接收方行为 |
|---|---|
| JSON 解析失败 / 缺 `act` / `arg` 非对象 | 丢弃并回 `{"ok":false,"error":...}` |
| 版本不支持 | 丢弃并回错误 |
| 未知 `act` | 丢弃并回错误 |
| `token` 不匹配 | 静默丢弃（不回包，避免探测） |
| 适配器执行异常 | 记录日志，保持上一个稳定状态或 `stop` |

## 7. 旧协议兼容（迁移期）

SDK 同时接受以下历史格式，便于 App 尚未切换到 v2 时平滑过渡：

| 格式 | 示例 | 映射 |
|---|---|---|
| 字符串 | `forward` `backward` `left` `right` `stop` `open` `close` | → `move(±1,0)` / `move(0,±1)` / `stop` / `open` / `close` |
| 数字 | `1`~`7` | 1 前 / 2 后 / 3 左 / 4 右 / 5 停 / 6 开 / 7 合 |
| 前缀 | `go2:forward`、`go2w:left` | 去掉前缀后按上表解析 |
| 侦察球二进制 | 11 字节，`01 81` 开头 | 由 `ball` 适配器原样转发 |

侦察球 11 字节帧（小端）：

```
[0:2]  01 81      [2] 控制字 00 正常 / 20 锁定 / 40 解锁
[3:5]  steer int16（左负右正）   [5:7] drive int16（前正后负）
[7]    servo      [8] turn_speed
[9:11] CRC16/MAXIM（poly A001, init 0000, xor FFFF，大端）
```

新实现不要求支持旧协议；若要支持，必须与上表逐字节一致。

## 8. 一次完整会话

```
App → SDK   {"v":2,"act":"hello"}
SDK → App   {"ok":true,"type":"ball","actions":["move","stop"],
             "max_speed":{"drive":1000,"steer":1000},"deadman_ms":400,...}

App → SDK   {"v":2,"seq":1,"act":"move","arg":{"vx":1.0,"wz":0.0}}
App → SDK   {"v":2,"seq":2,"act":"move","arg":{"vx":1.0,"wz":0.0}}   （每 50ms 重复）
App → SDK   {"v":2,"act":"stop"}                                      （松手）
```

若 App 在 400ms 内没有继续发送 `move`，SDK 会自行 `stop`，不需要 App 补发超时包。

## 9. 实现检查清单（用其他语言重写 SDK 时）

- [ ] 单数据报解析为一条 JSON，拒绝非法 UTF-8 / 非法 JSON
- [ ] 校验 `v`，未知版本直接丢弃
- [ ] `move` 更新目标速度并刷新「最后收到时间」
- [ ] 按 `publish_hz` 周期向设备下发，超过 `deadman_ms` 自动 `stop`
- [ ] `stop` 幂等，且只下发一次
- [ ] 离散动作只执行一次，不进入心跳
- [ ] `seq` 相同则丢弃
- [ ] 配置了 token 时校验，失败静默丢弃
- [ ] `hello` 返回 `type / actions / max_speed / deadman_ms / publish_hz`
- [ ] 进程退出前向设备发一次 `stop`

---

## 10. 安全提示

协议本身无加密、无认证（局域网场景）。部署时请注意：

- 不要把控制端口暴露到公网；如需跨网，加 VPN 或反向代理并启用 `--token`；
- 首次带载前架空设备、清空周边、准备物理急停；
- `deadman_ms` 不要设得过大（建议 300~800ms），否则掉线后设备会继续运动。
